# Security Policy

## Supported Versions

We provide security updates for the following versions of the project. Users are strongly encouraged to upgrade to the latest supported version to ensure they receive timely security fixes.

| Version | Supported          |
| ------- | ------------------ |
| v4.x    | :white_check_mark: |
| v3.x    | :white_check_mark: |
| v2.x    | :x:                |
| < v2.x  | :x:                |

> **Note**: Unsupported versions will not receive security patches or bug fixes. We recommend always using the latest stable release for optimal security.

## Reporting a Vulnerability

We take security seriously and appreciate responsible disclosure from the community. If you discover a security vulnerability in this project, please report it to us via [GitHub Issues](https://github.com/dingdayu/async/issues).

### What to Include:
- A clear description of the issue.
- Steps to reproduce the vulnerability.
- The potential impact or risk.
- Any relevant environment or configuration details.

### Response Process:
- We aim to acknowledge your report within **7 business days**.
- If the vulnerability is confirmed, we will work with you to understand and resolve the issue.
- Once a fix is released, we will credit you (if you wish to be acknowledged).
- If the report is determined not to be a security issue (e.g., misconfiguration or third-party dependency), we will explain our reasoning and suggest next steps.

Thank you for helping make this project more secure!
